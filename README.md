## 二、五条结论

**1. 0854 里不考 408 的路只剩两条**

2026 是统考化大年，南方候选校的计算机技术（085404）、软件工程（085405）几乎全部改考 408（重大 / 中南 / 武大 / 南大 / 厦大 / 暨南 / 苏大 …）。在「不考 408 + 选调名单内 + 南方 + 数二英二」四重约束下，只剩：

- **控制工程**（考自控）← 对计算机本科是跨考但只需攻一门
- 通信类（考信号）

⇒ 控制工程不是「选项之一」，而是**唯一出口**。单门自控对 3~4 个月冲刺也刚好卡得住；408 四门对在职备考几乎不可能。

**2. 真正匹配「数二英二 + 自控」的 985 只有 5 所**

东北大学、中南大学、重庆大学、西北工业大学、山东大学。

**4 所曾被误判的已更正**：哈工大 / 大连理工 / 华中科技 / 电子科技大学控制专硕实考**数一英一**（801 / 854 / 829 / 839），与配置冲突，已移出可报范围（华科数一单科线甚至划到 105 分）。

**3. 26 届是大年，全线暴涨，基于 25 届的「友好」判断全部作废**

| 学校 | 25 届 | 26 届 | 变化 |
|---|---|---|---|
| 东北大学 | 359 | **398** | +39（均分 421） |
| 重庆大学 | 305 | **340** | +35（专硕均分 408，但招 92~96，985 里最多） |
| 西北工业大学 | 310 | **375** | +65 |
| 河海大学 | 365 | **376** | +11 |
| 华北电力(保定) | 贴国家线 264 | 线仍低 | 但一志愿均分 375.6，「过线就录」不成立 |
| 山东大学 | — | 线 320 | 实录 389、均分 409 —— **线低 ≠ 好考** |

**4. 反向规律：考研难度 ≠ 选调出线难度（这条最重要）**

- 985：单校江西录取席位 **8~49 人**，名额厚，进校后容易出线
- 211：单校席位 **2~7 人**（部分 0~1 人），名额薄，反而更难出线

⇒ 打法应是**冲 985 为主**（名额厚），名单内工科 211 只作保底确保「能开门」。这和大家直觉里「211 好考所以稳」正好相反。

**5. 志愿梯度**

- **冲**：重庆大学（26 线 340 / 招 92~96 / 985 里招最多 / 不压分）→ 中南大学（355 / 招 55~63 / 长沙离家近）
- **保**：南京航空航天（数二**英一** + 820 自控 / 招 82）、合肥工业大学、西南交通大学（均待核科目）
- 厦大萨本栋（300 线）只招 5 人，是赌运气不是保底

## 四、口径与局限

**口径**

- 「26 届」= 2026 年 3 月复试、2026 年 9 月入学（即 26 考研）。
- 复试线 = 学院二次划线（真实进面门槛），不是校线；录取最低 / 均分 = 拟录取名单实算。
- 录取人数为**统考一志愿实际录取**（不含推免）。
- 江西选调席位 = 该校 2026 江西定向选调**实际拟录人数**（来源各高校就业网公示，非公告配额）。

**局限（重要）**

1. **科目每年微调**。标「待核」的学校（合工大 / 西南交大 / 武理 / 矿大 / 地大武汉 / 江南 / 苏大等）必须查当年招生专业目录逐校确认是否还考数二 + 自控。
2. **已知的科目变动风险**：西工大控制 27 届已从数二英二改数一英一（已退出可报范围）；海南大学控制 + 仪器 27 届改 408。趋势是**控制工程正在被 408 / 数一吞并**。
3. **408 扩容的结构性影响**：北邮 AI、北航 AI 网安、杭电 AI 大数据等 27 届改 408，会把更多 CS 考生挤向仍考自控的控制工程 → 控制的结构性竞争在上升，可能抵消大小年回落。
4. **大小年**：26 大年 → 27 小年回落 → 28 可能反弹回大年。建议按**大年强度**准备（目标分取最难年），遇上小年就是赚。
5. **数据是选校地图，不是保证书**。每年 2~3 月新公告出来后，必须用这套表重筛一遍。
6. 标「未列」的格子 = 本轮未逐一核实具体数字，不代表没有数据。

**选调的政治条件（4 选 1）**：党员 / 学生干部 / 校级荣誉或二等以上奖学金 / 参军。已排除党员与参军路线 ⇒ 主冲**二等以上学业奖学金**，顺手当班干。
